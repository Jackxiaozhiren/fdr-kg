# Data and Artifact Availability

FDR-KG depends on third-party knowledge-graph datasets and model artifacts. Redistribution rights for those assets are governed by their original providers and licenses.

## Public repository

This repository provides source code and selected derived benchmark outputs. The currently committed files under `experiments/results/` are retained for transparency as an earlier public experiment state; they are not the frozen manuscript evidence package.

## Manuscript evidence package

The manuscript-facing archival release should provide all redistributable derived evidence required to verify the reported tables and figures, together with SHA-256 checksums and exact configuration metadata. Inputs that cannot legally be redistributed should be referenced by stable provider identifiers and accompanied by acquisition and preprocessing instructions.

## Persistent archive

After the manuscript evidence is frozen and verified, create a versioned GitHub Release and archive that exact release in a DOI-issuing repository such as Zenodo. The manuscript Data Availability Statement should cite the DOI of that frozen release rather than an unversioned branch URL.
